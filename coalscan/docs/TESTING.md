# Testing, Calibration, and Verification Guide (CSC-203)

> **Prototype Notice:** All tests use synthetic benign PE structures or harmless byte sequences generated by `coalscan/fixtures/generate_fixtures.py`. Never use or execute real malware.

## 1. Running the Full Test Suite

```powershell
python -m pytest -v
```

## 3. Calibration vs. Held-Out Protocol

1. **Up-Front Split:** In `coalscan/fixtures/generate_fixtures.py`, 16 benign fixtures are assigned up front to either `set="calibration"` (8 files) or `set="heldout"` (8 files) in `coalscan/fixtures/manifest.csv`.
2. **Calibration Gate (`python -m coalscan.tests.calibration`):** Runs `DEFAULT_BANDING_CONFIG` on the `calibration` set and asserts that every calibration benign file scores `0-3` with no High rule (`Routine`).
3. **Freeze & Held-Out Report (`python -m coalscan.tests.heldout`):** With `DEFAULT_BANDING_CONFIG.calibrated_and_frozen == True`, evaluates the `heldout` set once and reports that 7/8 files land in `Routine` and 1/8 (`hold_benign_08_compressed_media_app.exe`, combining `R01` + `R09` compressed media section) lands in `Review` (12.5%). Held-out results are only reported and never used to tune weights.
